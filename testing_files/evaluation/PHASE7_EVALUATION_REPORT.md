# Phase 7 Evaluation Report

## Scope and protocol

The classifier is MobileNetV3-Small trained on six PlantVillage classes. The
saved checkpoint was selected using validation accuracy; the reported test
figures come from the separate 1,379-image held-out split. This split is an
in-distribution benchmark, so it should not be presented as field performance.

Run the reproducible evaluation with:

```powershell
.\.venv\Scripts\python.exe testing_files\evaluation\run_phase7_evaluation.py
```

It reads the held-out split from `testing_files/data/processed/test/` and
writes `held_out_test_evaluation.json` and a labelled confusion-matrix PNG
under `testing_files/evaluation/`. The source split manifest is kept at
`testing_files/data/plantvillage/splits/color_test.txt`.
For a separately collected, labelled external ImageFolder whose six class
folders exactly match `models/class_names.json`, run:

```powershell
.\.venv\Scripts\python.exe testing_files\evaluation\run_phase7_evaluation.py --external-dir path\to\external_set
```

External outputs use the `external_*` names and do not overwrite official test
metrics.

Existing baseline artifact: `classifier_results.json` (13 October 2026).

| Metric | Result |
| --- | ---: |
| Accuracy | 97.61% |
| Macro precision | 97.92% |
| Macro recall | 97.77% |
| Macro F1 | 97.84% |
| Test images | 1,379 |

Per-class results are contained in `classifier_results.json` and regenerated by
the Phase 7 runner. The most important observed confusion is between tomato
early blight and tomato late blight: 10 early-blight images were predicted as
late blight, and 11 late-blight images were predicted as early blight.

## Classifier-score review bands

The application labels scores below 0.60 inconclusive and prevents a
disease-specific advisory when the selected crop conflicts with the predicted
crop. Scores from 0.60 to below 0.85 are shown as moderate; scores at or above
0.85 are shown as high. These cutoffs are conservative UI review rules, not
calibrated probabilities or guarantees.

The reproducible evaluator reports held-out accuracy within each score band.
On the current 1,379-image PlantVillage test split, the low band contained 23
images at 60.87% accuracy, the moderate band 72 images at 76.39% accuracy, and
the high band 1,284 images at 99.45% accuracy. This is an in-distribution
benchmark of the existing cutoffs, not independent threshold tuning or
validation on field images. The held-out split must not be reused to tune the
model or claim general confidence calibration.

## Limitations and failure cases

- PlantVillage images are generally clean, leaf-centred, and controlled; field
  photos can contain different lighting, backgrounds, multiple leaves, pests,
  nutrient issues, or more than one disease.
- The classifier only recognises six target classes. A top prediction is not a
  confirmed diagnosis and may be unsuitable for an unseen crop or disease.
- Early and late tomato blight are the recorded primary confusion pair.
- Visual descriptions and translations depend on an external/local language
  model and require human grounding review before quality claims are made.
- FAISS retrieval is restricted to the curated knowledge records; a retrieved
  statement is not a substitute for locally approved agricultural guidance.
