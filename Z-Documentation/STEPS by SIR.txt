PROJECT 4
a) Project Title
AgriVision AI — Crop Disease Understanding and Farmer Advisory Assistant

b) Detailed Project Description
Crop diseases can reduce agricultural productivity significantly. A farmer may be able to photograph a leaf but may not know what symptoms indicate disease or what preventative action to take.

This project builds a multimodal GenAI agricultural assistant.

The student uploads an image of a leaf.

The system:

examines the image
predicts/identifies the disease category
explains the visible symptoms
retrieves relevant agricultural information
generates an easy-to-understand advisory
clearly indicates uncertainty
This makes the project a combination of:

Computer Vision + Multimodal GenAI + RAG

The goal is not to claim that the application replaces an agricultural expert.

c) Dataset Details (freely available)
PlantVillage Dataset
The PlantVillage repository currently describes the dataset as an open-access collection of 54,306 healthy and diseased plant-leaf images, covering 14 crop species and 26 diseases. It also provides an accessible Hugging Face version.

Official/public repository
https://github.com/spMohanty/PlantVillage-Dataset

Hugging Face dataset
https://huggingface.co/datasets/mohanty/PlantVillage

The repository provides predefined train/test splits designed to respect leaf grouping and reduce leakage.

Recommended student subset
Students should initially select 3–5 diseases instead of all 26.

Example:

Tomato
Potato
Grape
Apple
Corn
This dramatically reduces laptop training requirements.

d) Technical Requirements
Recommended multimodal model
Gemma 3 4B

Gemma 3 4B is an image-text model available through Hugging Face and supports image + text interaction.

Laptop recommendation
16 GB RAM recommended
GPU not mandatory for experimentation
8 GB RAM students should use API inference instead
Alternative
Use a multimodal Gemini model through the Gemini API.

Google currently provides a free developer tier for selected Gemini models, with usage limits.

Supporting computer vision model
